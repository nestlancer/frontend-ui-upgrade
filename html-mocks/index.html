5. Why Current Live UI Graded C / C+ — And How This Rebuild Fixes It

Defect Category Observed in Current Screenshots (C / C+) Fixed in HTML Rebuild (A+ Target)
1. Multi-Brand Color Split Marketing uses #0B7A71 teal, Client Portal switches to TailAdmin blue #465fff + electric violet #3500ff stacked on the same Checkout screen. Single #0B7A71 12-step Radix brand scale across Marketing, Client Portal, and Admin Console.
2. Four-Typeface Clash Project Detail & Checkout mix Fraunces display serif headings with Outfit, Instrument Sans, and Inter; money values lack tabular alignment. Geist Sans + Geist Mono (tabular-nums) everywhere; all INR amounts, GST, IDs, and dates align to the pixel.
3. Broken Layout & Overlaps Project progress timeline dots literally overlap heading text (○Milestone Approved); Admin tables clip Oct 5, 2026 and wrap Manage → arrows; Portfolio sticky nav detaches mid-page. 2-column CSS grid timeline rail, compact monospaced short-IDs (REQ-530E) with copy buttons, and non-wrapping action cells.
4. Redundant Card & Status Clutter Project Detail repeats "In progress / 40% complete" 4 times above the fold and renders identical "Latest progress" and "Recent updates" cards back-to-back. Single unified project lifecycle header bar + clean 6-tab workspace without duplicate cards.
5. Amateur Form Chrome Register, Contact, and New Request place (?) tooltip icons on obvious fields ("First name *", "Email *"); Bank/UPI transfer uses unstyled browser <input type="file">. Clean shadcn/Radix form controls, inline helper hints only where needed, and custom drag-and-drop UTR receipt uploader.
